 ## Tecnologias Aplicadas
 Para la construcción de este proyecto me enfoqué en la escritura de código limpio, accesible y optimizado para motores de búsqueda (SEO):
- **HTML5 Semántico:** Implementación de etiquetas estructurales (`<header>`, `<main>`, `<section>`, `<article>`, `<figure>`) para garantizar una correcta jerarquía de la información.
- **CSS3 Moderno:** Uso de **Flexbox** para la alineación y distribución horizontal proporcional de las capturas de proyectos, previniendo distorsiones visuales mediante técnicas avanzadas de ajuste de imágenes (`object-fit`).
- **Arquitectura Responsiva:** Adaptabilidad fluida garantizada en dispositivos móviles mediante Media Queries.
